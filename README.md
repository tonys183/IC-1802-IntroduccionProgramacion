# IC-1802 — Introducción a la Programación

Soluciones a ejercicios del curso Introducción a la Programación (IC-1802), basados en el libro *Fundamentos de Programación* de Eddy Ramírez Jiménez.

Los ejercicios están implementados en Python y se encuentran en la carpeta `Tareas/`, organizados según la numeración del libro.
